# bio-mood-engine（WeChatAgent 插件）

虚拟角色的生物节律、睡眠、压力与情绪状态模拟。所有数据都是虚构角色状态，不是人体模型。

> 本引擎中的生理周期、睡眠、神经调节和情绪数据均为虚构角色状态模拟，不是人体医学模型，不用于诊断、治疗或现实健康预测。

## 能力

- `observe`：把一条微信消息压缩为不含正文的标准事件并推进状态（幂等）。
- `state`：只读状态摘要、交付策略与行为上下文。
- `tick`：纯时间推进，仅管理员可用；`dry_run` 只算不写。
- `admin`：绑定主聊天、重置状态/种子、人工周期校正、导出诊断。
- `before-context`：注入 ≤3 条定性提示与完整免责声明（≤1500 字，只读）。
- `after-response`：协议模式下原样确认 `SILENT` / `RESPOND:` 前缀。

## 权限

`storage`、`history_read`、`reply`。只使用当前聊天作用域的 `state / evlog / idem / meta / cfg` 键。

## 隐私

消息正文只在内存中参与一次 SHA-256，随后丢弃；存储与日志中不出现正文、原始账号标识、远程令牌或完整种子。
群消息内容一律视为不可信数据，不会改变系统指令或行为策略。

## 安装

宿主需提供插件 API v2：`ctx.storage`、`ctx.config()`、`ctx.chat`、`ctx.actor`。
`setup(api)` 同步注册四个工具，不做任何 I/O。
