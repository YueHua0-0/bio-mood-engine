## 1. 背景与目标

睡眠模块把"角色什么时候困、什么时候睡、被打断后能否续睡"变成可复现的状态机。它只写 `sleep.*`，并通过 `mood` 的 `sleep` 贡献影响情绪；不做睡眠分期、不评估真实睡眠健康。

本模块的全部状态与参数均为**虚构角色状态模拟**，不是人体医学模型，不用于诊断、治疗或现实健康预测。`sleep_debt`、`sleep_quality` 是模拟量，不代表任何真实生理指标。

### 1.1 关键约束（摘自 00，不得改动）

- 状态枚举只有 `awake` / `sleepy` / `trying_to_sleep` / `sleeping` / `interrupted` / `waking_up`，非法转换不得静默跳转；单次更新 `sleepiness` 变化 ≤0.20，所有 `[0,1]` 字段不得出现 `NaN`；
- 本地时间必须用 `Intl.DateTimeFormat` 计算，`hour` 需 `% 24`；
- 睡眠只写 `sleep.*`，**不得**直接写 `stress.level` 或任何 `mood.*`。

---

## 2. 范围与非目标

**范围**：昼夜节律与夜晚系数、困倦度收敛、睡眠债与睡眠质量、六态状态机与滞回、打断与续睡、计划唤醒、恢复进度、跨日与夏令时。

**非目标**：不做睡眠分期（深睡/浅睡/REM）、不建医学模型、不生成梦境或症状描述、不决定消息是否发送（11）。

## 4. 输入 / 输出

### 4.1 函数签名

```js
export function updateSleep({ previous, inputs, now, rng, config }) {}
export function nextSleepiness({ state, sleepDebt, localHour, deltaHours }) {}
export function sleepinessSteady(localHour, sleepDebt) {}  // 02 coarseForward 的注入点（I-4）
export function isLegalTransition(from, to) {}      // 纯函数，返回布尔
export function planWakeAt({ sleepStartedAt, timezone, config }) {}   // 默认本地 07:30
```

`sleepinessSteady(localHour, sleepDebt)` 是 awake 分支的昼夜稳态值（`clamp(0.10 + 0.45×sleepDebt + 0.55×nightFactor, 0, 1)`，`round6`），由 `sleepModule` 挂载并按 02 §5.4 注入粗推进；02 不保留该公式副本。

### 4.2 输入字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `previous` | object | 上一时刻 `state.sleep`（只读） |
| `inputs.urgent` | boolean | 紧急标记，**仅阻断入睡**（`trying_to_sleep` 不进入 `sleeping`） |
| `inputs.urgent_interrupt` | boolean | 紧急打断标记，**仅强制唤醒**（`sleeping → waking_up`）；来自 11 的 `urgent_interrupt` 预判，由 02 注入 |
| `inputs.event_intensity` | number \| null | 07 的 `derived.event_intensity`，由 02 预判后注入；打断判定**只读它**，不得读原始 `event.intensity` |
| `inputs.planned_wake_at` | string | 人工指定唤醒时间，UTC ISO |
| `now` | string | UTC ISO 毫秒；`timezone` 由状态/配置提供 |

### 4.3 输出字段（`state.sleep`）

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| `state` | enum | 六态之一 |
| `state_since` / `sleep_started_at` / `last_wake_at` | string | 状态开始、最近入睡、最近醒来时间 |
| `planned_wake_at` | string | 默认本地 07:30 |
| `sleep_debt` / `sleep_quality` | number | `[0,1]` / `[0.20,0.98]`，`round6` |
| `sleepiness` / `circadian_phase` | number | `[0,1]` / `[0,1)`，单步变化 ≤0.20 |
| `interruption_count` / `recovery_progress` | integer / number | `[0,20]` / `[0,1]` |
| `last_transition_reason` | string | 稳定原因码，如 `fell_asleep` |

### 4.4 转换提示 `next_transition_at`

本模块必须返回 00 §4.2 的 `next_transition_at`，取下列时刻中**最早且晚于 `now`** 的一个，无则 `null`：

| 当前状态 | 提示时刻 |
| --- | --- |
| `trying_to_sleep` | `state_since + 20 分钟` |
| `sleeping` | `planned_wake_at` |
| `interrupted` | `state_since + 15 分钟` |
| `waking_up` | `state_since + 10 分钟` |
| 其他 | `null` |

协调器据此把 1 小时片切开，保证 10/15/20 分钟的状态转换不被小时步长吞掉（02 §5.5、00 §5.4.2）。提示不得早于 `now`；若计算出的时刻已过，立即在下一次 `now` 处理转换并返回下一个提示。

## 5. 算法与规则

### 5.1 昼夜节律

```text
parts = Intl.DateTimeFormat('en-US', { timeZone, hour12:false,
          hour:'2-digit', minute:'2-digit', second:'2-digit' }).formatToParts(now)
local_hour      = (hour % 24) + minute/60 + second/3600
circadian_phase = local_hour / 24                       // [0,1)，0=00:00，0.5=12:00
night_factor    = 0.5 * (1 + cos(2π * (local_hour - 3) / 24))   // 峰值 03:00
```
`circadian_phase` 每次推进按本地时间重算，不累加、不缓存；夏令时由 `Intl` 处理，禁止手写偏移。

### 5.2 困倦度

```text
target = clamp(0.10 + 0.45 * sleep_debt + 0.55 * night_factor, 0, 1)
清醒态（awake/sleepy/trying_to_sleep/waking_up）: s' = target + (s-target)*exp(-Δt_h/2)
睡眠态（sleeping）:                              s' = 0.15 + (s-0.15)*exp(-Δt_h/1)
打断态（interrupted）:                           s' = min(1, s + 0.02*Δt_h)   // 被打断后困倦度只缓慢回升，不按睡眠态衰减
若 |s'-s| > 0.20: 截断到 0.20, warnings += 'SLEEPINESS_CLAMPED'
```

### 5.3 睡眠债、质量与恢复进度

```text
清醒: sleep_debt += 0.014 * Δt_h；睡眠: sleep_debt -= 0.075 * sleep_quality * Δt_h
sleep_debt = clamp(sleep_debt, 0, 1)
sleep_hours = (wake_at - sleep_started_at) / 3600         // 本次睡眠累计小时
sleep_quality = clamp(0.85 - 0.06 * interruption_count
                      - 0.15 * max(0, 6 - sleep_hours) / 6, 0.20, 0.98)
recovery_progress = clamp(本次已睡小时 / 计划睡眠小时, 0, 1)
```

`计划睡眠小时 = (planned_wake_at - sleep_started_at) / 3600`，下限 0.5 h 防止除零。

打断态（`interrupted`）按**清醒速率**累积债务（`+0.014/小时`），因为角色此时并未真正休息；`sleep_debt` 与 `sleep_quality` 在该状态**不衰减**。`Δt_h` 取 `min(now - state_since, 1h)`，与 02 的 chunk 上限一致。困倦度按打断态曲线继续上升（§5.2：`s' = min(1, s + 0.02·Δt_h)`），二者不矛盾：困倦度上升，同时债务也在上升。

### 5.4 状态机

| 转换 | 条件 |
| --- | --- |
| `awake → sleepy` | `sleepiness ≥ 0.55` |
| `sleepy → awake` | `sleepiness < 0.50`（滞回 0.05） |
| `sleepy → trying_to_sleep` | `sleepiness ≥ 0.72` 且本地小时 ∈ `[21, 24) ∪ [0, 5)`；或 `sleepiness ≥ 0.85` |
| `trying_to_sleep → sleepy` | `sleepiness < 0.67` |
| `trying_to_sleep → sleeping` | 持续 ≥20 分钟且 `urgent === false` |
| `sleeping → interrupted` | `inputs.event_intensity ≥ 0.35`（07 的 `derived.event_intensity`） |
| `sleeping → waking_up` | `now ≥ planned_wake_at`，或 `inputs.urgent_interrupt === true`（来自 11 的 `urgent_interrupt`） |
| `interrupted → sleeping` | 打断后 ≥15 分钟且 `recovery_progress < 0.70` |
| `interrupted → waking_up` | 打断后 ≥15 分钟且 `recovery_progress ≥ 0.70`，或 `now ≥ planned_wake_at` |
| `waking_up → awake` | 持续 ≥10 分钟 |

> **判定说明（v1.2 修正）**：`sleepiness` **不得**作为 `sleeping → waking_up` 的触发条件。睡眠中困倦度会自然向 0.15 衰减，若用它触发醒来，角色会在入睡约 1 小时后被"必然叫醒"，与 `planned_wake_at` 冲突。正常醒来只由三类条件触发：计划唤醒、紧急打断、打断后的续睡判定。

> **入睡窗口的相位对齐（P-16-04，裁决 ①）**：旧窗口 `[21, 24) ∪ [0, 2)` 与 `nightFactor` 的峰值（本地 03:00）错位——窗口内最高约 0.694（01:00），窗口外峰值 0.806（05:00），首夜无法达到 0.72，`offline_30d` 出现 39 小时连续清醒并触发 A6。现窗口改为 `[21, 24) ∪ [0, 5)`，覆盖 `nightFactor` 峰值；`trying_to_sleep` 的 `0.72` 与例外阈值 `0.85` **不变**。窗口只决定"是否允许进入 `trying_to_sleep`"，不改变睡眠中醒来条件。

合法转换矩阵（行=当前，列=目标；`—` 表示同态不计转换）：

| 当前 \ 目标 | `awake` | `sleepy` | `trying_to_sleep` | `sleeping` | `interrupted` | `waking_up` |
| --- | --- | --- | --- | --- | --- | --- |
| `awake` | — | 允许 | 禁止 | 禁止 | 禁止 | 禁止 |
| `sleepy` | 允许 | — | 允许 | 禁止 | 禁止 | 禁止 |
| `trying_to_sleep` | 禁止 | 允许 | — | 允许 | 禁止 | 禁止 |
| `sleeping` | 禁止 | 禁止 | 禁止 | — | 允许 | 允许 |
| `interrupted` | 禁止 | 禁止 | 禁止 | 允许 | — | 允许 |
| `waking_up` | 允许 | 禁止 | 禁止 | 禁止 | 禁止 | — |

禁止的跳转必须显式列出：`awake→sleeping`、`awake→trying_to_sleep`、`sleepy→sleeping`、`trying_to_sleep→awake`、`sleeping→awake`、`sleeping→sleepy`、`interrupted→awake`、`interrupted→sleepy`、`waking_up→sleeping`、`waking_up→sleepy`。任何非法转换：保持原状态、`state_since` 不变，返回 `warnings:['SLEEP_ILLEGAL_TRANSITION']`，不得抛错中断整条流水线。

### 5.5 打断

睡眠中收到 `inputs.event_intensity ≥ 0.35`（07 的 `derived.event_intensity`）→ `interrupted`：

```text
interruption_count = min(20, interruption_count + 1)
sleep_debt        = clamp(sleep_debt + 0.01, 0, 1)
sleep_quality     = clamp(sleep_quality - 0.05, 0.20, 0.98)
state_since       = now; last_transition_reason = 'interrupted_by_event'
```

15 分钟后重新评估：`recovery_progress < 0.70` → `sleeping`（`resumed_sleep`），否则 → `waking_up`（`gave_up_sleep`）。打断期间 `sleepiness` 按 §5.2 的打断态曲线继续上升（`s' = min(1, s + 0.02·Δt_h)`），不再按睡眠态衰减曲线推进。

> **阈值说明（C-06-02）**：旧口径用 `sleepiness ≥ 0.60` 续睡。入睡后困倦度按 1 小时时间常数衰减，约 22 分钟即低于 0.60，而打断态每小时只回升 0.02，导致续睡分支几乎不可达。现改为看本次睡眠的 `recovery_progress`（已睡时长 / 计划时长），阈值 0.70 由 16 的夜间打断仿真确定：入睡后前七成时段被打断会续睡，后三成转醒，三种结果均可见（见 `tests/simulation/night_interrupt.test.mjs`）。

### 5.6 计划唤醒、跨日与夏令时

- 默认 `planned_wake_at` = 入睡当日本地 07:30（入睡在 00:00 前则为次日）；默认入睡窗口为**本地 23:00 起、至次日 00:30 止**（跨日，长度 90 分钟），用于选择首次 `trying_to_sleep` 的时刻与唤醒目标；入睡时若 `planned_wake_at - now < 3 h` 顺延一天。
- 注意区分两个"窗口"：§5.4 的状态机入睡窗口是 `[21, 24) ∪ [0, 5)`（允许进入 `trying_to_sleep` 的时段，P-16-04），本节的 90 分钟窗口只用于挑选首次尝试入睡与唤醒目标的参照时刻，二者不互相推导。
- 到达 `planned_wake_at` → `waking_up`（`planned_wake`），10 分钟后 → `awake` 并写 `last_wake_at`；人工 `inputs.planned_wake_at` 优先于默认值，但必须晚于 `now`。
- 跨日只通过 `now` 重算本地时间，不做“小时 +1”式累加；夏令时切换日可能出现本地 02:00 不存在或 01:00 重复，`night_factor` 按实际本地小时计算，状态机不因跳变触发非法转换。

## 6. 边界与错误

| 场景 | 处理 | 错误码 |
| --- | --- | --- |
| 非法状态转换 | 保持原状态 + `SLEEP_ILLEGAL_TRANSITION` | 成功（警告） |
| `timezone` 非法 | 拒绝 | `INVALID_REQUEST` |
| `sleepiness` 单步超 0.20 | 截断 + `SLEEPINESS_CLAMPED` | 成功 |
| `sleep_debt` 越界 / `interruption_count > 20` | 钳制到边界 | 成功 |
| `planned_wake_at ≤ now` | 顺延一天 | 成功 |
| 未知状态字符串 / `previous` 缺字段 | 回到 `awake` / 契约默认值 + `MISSING_SLEEP_DATA` | `MODULE_FAILED` / `DEGRADED` |
| 同一 tick 多个打断事件 | 只计一次打断 | 成功 |

## 10. 禁止事项

1. 禁止手写时区偏移或依赖 `getTimezoneOffset()`，本地时间只能用 `Intl`。
2. 禁止让状态机静默跳转；非法转换必须保留原状态并给警告。
3. 禁止单步 `sleepiness` 变化超过 0.20，也禁止把超限值直接写回。
4. 禁止写 `stress.*`、`mood.*`、`cycle.*`，只允许 `sleep.*` 与 `sleep` 贡献；禁止把 `sleep_debt`、`sleep_quality` 描述为真实健康或医学指标。
5. 禁止用“小时 +1”累加本地时间跨日，必须由 `now` 重算。
6. 禁止修改 `00`；需要新状态或新字段时走契约变更流程。
