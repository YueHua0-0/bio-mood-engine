## 1. 背景与目标
神经调节层是周期、睡眠、压力与情绪之间的**中间变量**：把多个上游来源压缩成六个无歧义的抽象特征，避免情绪引擎直接对原始输入做线性堆叠。它只写 `regulation.*`，不写 `mood.*`，也不回写 `cycle.*` / `sleep.*` / `stress.*`。

六个特征全部是**虚构角色状态模拟**中的中性抽象特征，不对应任何真实神经递质、浓度、受体或医学指标，不用于诊断、治疗或现实健康预测。实现与文档中禁止出现真实递质名称，禁止"某特征 = 某物质"的表述。

### 1.1 关键约束（摘自 00，不得改动）
- 六个维度均为 `[0,1]`，持久化前 `round6`，禁止 `NaN` / `Infinity` / `-0`。
- 单次更新任一维度变化 ≤0.05；超出必须裁剪并警告 `CLAMPED_DELTA`。
- 只写 `regulation.*`；周期与睡眠的原始影响向量不得在本模块二次写入 `mood`。
- 时间只来自 `now`，不读系统时钟；随机数 v1 不消费。
- `model_version` 固定写 `1`。
## 2. 范围与非目标
**范围**：六维目标公式；周期阶段到四个标量的映射；45 分钟惯性；单次 0.05 上限；`comfort_signal`；上游缺失降级；贡献分解与 `reason_codes`。

**非目标**：不计算情绪维度（09）；不判断行为（10/11）；不重新解释周期阶段（05）；不重新计算睡眠债或压力（06/07）；不引入医学或递质语义；不新增状态字段。

## 4. 输入 / 输出
### 4.1 函数签名

```js
export function updateRegulation({ previous, inputs, now, rng, config }) {}
export function targetRewardSensitivity(x) {}
export function targetArousal(x) {}
export function targetThreatSensitivity(x) {}
export function targetCalmRegulation(x) {}
export function targetSocialReassuranceDrive(x) {}
export function targetFatigueLoad(x) {}
export function cycleScalars(phase) {}        // 05 阶段 -> 四个标量
export function comfortSignal(activeEvents) {}   // 07 负强度占比
```

六个 `target*` 必须是纯函数：相同入参逐位相同，不做时间推进、不读 `previous` 以外的状态。

### 4.2 输入字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `previous` | object | 上一时刻 `state.regulation`；缺字段按 `MISSING_REGULATION_DATA` 降级 |
| `inputs.cycle.phase` | enum | 00 §2.5 的四个 `_like` 阶段 |
| `inputs.sleep.sleep_debt` / `sleep_quality` / `sleepiness` | number | 来自 06，`[0,1]` |
| `inputs.stress.level` | number | 来自 07，`[0,1]` |
| `inputs.stress.active_events` | array | 用于 `comfort_signal` |
| `inputs.mood.energy` / `stability` / `closeness_need` | number | **上一 tick** 的 `mood.*`（09 尚未运行） |
| `inputs.dt` | integer | 本次推进的实际秒数（`≥ 0`），由 02 按 chunk / 事件阶段传入；缺失或非法即 `MODULE_FAILED`（00 v1.7.6 §4.1） |
| `now` | string | UTC ISO 毫秒，唯一时间来源 |

**时序说明**：02 §5.5 的顺序是 `regulation` 先于 `mood`，所以本模块读取的 `energy` / `stability` / `closeness_need` 只能是上一 tick 的值（滞后一拍），不得读取同一 tick 的 09 输出，否则形成环。缺失时用 09 的 home 值（0.60 / 0.65 / 0.45）并追加 `MISSING_MOOD_DATA`。

**dt 说明**：惯性 `blend = 1 - 2^(-dt/2700)` 直接决定本次步进走完差距的百分比，必须使用 02 传入的实际 `dt`。模块**不得**从 `now - last_tick_at` 推算、不得用 3600 兜底；`inputs.dt` 缺失、为负或非整数一律 `MODULE_FAILED`。

### 4.3 输出（`state.regulation`）

| 维度 | 含义（中性抽象） |
| --- | --- |
| `reward_sensitivity` | 对正向反馈的敏感程度 |
| `arousal` | 整体激活水平 |
| `threat_sensitivity` | 对潜在威胁线索的敏感程度 |
| `calm_regulation` | 维持平稳的调节能力 |
| `social_reassurance_drive` | 寻求社会确认的驱力 |
| `fatigue_load` | 累积疲劳负荷 |

`contributions` 只允许 `regulation.<dim>` 六个维度键，来源键固定为 `base` / `cycle` / `sleep` / `stress` / `comfort` / `mood_lag` / `inertia` / `clamp`，无变化写 0，且同一维度内各来源之和必须等于实际变化量。

## 5. 算法与规则
### 5.1 周期映射（由 05 阶段决定，冻结）

| 阶段 | `cycle_reward` | `cycle_energy` | `cycle_sensitivity` | `cycle_social` |
| --- | --- | --- | --- | --- |
| `menstrual_like` | 0.35 | 0.40 | 0.60 | 0.40 |
| `follicular_like` | 0.65 | 0.62 | 0.45 | 0.60 |
| `ovulatory_like` | 0.70 | 0.58 | 0.50 | 0.65 |
| `luteal_like` | 0.40 | 0.42 | 0.62 | 0.42 |

阶段缺失或非法时四个标量取 `0.50`，追加 `MISSING_CYCLE_DATA`；不得让 `cycleScalars` 抛错中断流水线。映射只读阶段标签，不读 `cycle_day`，避免边界抖动被放大。

### 5.2 `comfort_signal`

```text
neg = Σ max(0, -remaining_i)          // 只统计负强度事件
all = Σ |remaining_i|
comfort_signal = (all > 0 && neg > 0) ? clamp(neg / all, 0, 1) : 0
```

无事件、全为正向事件或分母为 0 时取 0。`comfort_signal` 只奖励"确实收到安慰"的情形，不把压力消失误判为安慰。

### 5.3 六个目标公式

```text
reward_sensitivity = 0.40 + 0.15*cycle_reward
                          + 0.15*(1 - sleep_debt)
                          + 0.10*(1 - stress)
                          + 0.10*comfort_signal
                          - 0.05*previous.fatigue_load

arousal            = 0.35 + 0.20*cycle_energy
                          + 0.20*(1 - sleep_debt)
                          + 0.15*(1 - sleepiness)
                          + 0.10*stress

threat_sensitivity = 0.30 + 0.20*stress
                          + 0.15*cycle_sensitivity
                          + 0.10*sleep_debt
                          + 0.10*(1 - stability)

calm_regulation    = 0.55 + 0.15*sleep_quality
                          + 0.10*(1 - stress)
                          - 0.10*previous.fatigue_load
                          - 0.05*stress

social_reassurance_drive = 0.35 + 0.20*closeness_need
                                + 0.15*(1 - energy)
                                + 0.10*stress
                                + 0.10*cycle_social

fatigue_load       = 0.20 + 0.50*sleep_debt
                          + 0.25*(1 - sleep_quality)
                          + 0.10*(1 - sleepiness)
```

规则：

1. 每个结果先 `clamp(0,1)` 再 `round6`。
2. `reward_sensitivity` 与 `calm_regulation` 公式中的 `fatigue_load` 取**上一 tick** 的 `previous.fatigue_load`（`previous` 即 `state.regulation`，按 00 §3.1 必然含六维），避免同 tick 自引用；本 tick 新 `fatigue_load` 只用于输出与下游 09。`previous.fatigue_load` 缺失时按 0.30 处理并追加 `MISSING_REGULATION_DATA`。
3. 六个公式中的 `sleep_debt`、`sleep_quality`、`sleepiness`、`stress`、`energy`、`stability`、`closeness_need` 全部先 `clamp(0,1)` 再代入，越界值不得直接参与乘法。
4. 公式权重冻结，不得按角色或配置调参；角色差异由上游取值表达。
5. **上下文特征约束（P-08-01）**：`cycle_*` / `sleep_*` / `stress` 只用于塑造稳态目标，不得作为瞬时冲击的放大器。任一上游单步变化 `Δ` 对任一 regulation 维度的增量满足 `|Δr| ≤ w_max · blend(dt) · Δ`，其中 `w_max = 0.20`（`threat_sensitivity` 的 `stress` 项最大），并同时受 §5.4 的 `0.05` 裁剪。代入 09 §5.2 的系数 `0.10`（`closeness_need` 为 `0.08`）与 `alpha[d] ≤ 1`，对 `mood` 的间接贡献增量上界为 `|Δcontrib| ≤ 0.10 · w_max · blend(dt) · Δ`：`Δ = 0.06`、`dt = 1 h`（`blend = 0.6031`）时为 `7.24e-4`。该上界由 R17 锁定。

### 5.4 惯性

```text
dt    = 本次推进秒数（02 已分块，单步 ≤3600）
blend = 1 - 2 ** (-dt / 2700)          // 45 分钟半衰期
raw   = (target - prev) * blend
delta = clamp(raw, -0.05, 0.05)         // 超出追加 CLAMPED_DELTA
next  = clamp(prev + delta, 0, 1)
```

- `dt = 2700` 时走完差距的 50%；`dt = 5400` 走完 75%。
- 裁剪只针对单次变化，不改变目标值；下一 tick 继续按 45 分钟惯性逼近。
- `next` 必须 `round6`；`prev` 或 `target` 出现非有限值时按 `INVALID_REQUEST` 拒绝。
- 长时间运行时不得出现持续贴边或周期振荡；稳态应满足 `|next - target| < 0.01`。

### 5.5 贡献分解

```text
blend = 1 - 2 ** (-dt / 2700)
每个加权项 contrib_i = raw_term_i * blend
contrib['inertia']   = -prev * blend
contrib['clamp']     = 实际 delta - (Σ contrib 除 clamp 外)
```

八个来源键在每个维度下都必须出现，缺失写 0；`Σ contributions == next - prev`（容差 `1e-9`）。`clamp` 仅在实际裁剪或边界饱和时非 0，用于解释"公式之外"的变化。

### 5.6 降级与 `reason_codes`

- 周期缺失：四个标量 0.50 + `MISSING_CYCLE_DATA`。
- 睡眠缺失：`sleep_debt=0.15`、`sleep_quality=0.70`、`sleepiness=0.25` + `MISSING_SLEEP_DATA`。
- 压力缺失：`level=0.15`、空事件列表、`comfort_signal=0` + `MISSING_STRESS_DATA`。
- 上一 tick `mood` 缺失：`0.60 / 0.65 / 0.45` + `MISSING_MOOD_DATA`。
- `reason_codes` 最多 16 个，稳定命名：`sleep_debt_high`、`stress_high`、`comfort_received`、`luteal_like`、`menstrual_like`、`cycle_data_missing`、`clamped_delta`、`saturated_high`、`saturated_low`。
- 降级用默认值，不得编造观测值，也不得因此跳过惯性。

## 6. 边界与错误
| 场景 | 处理 | 错误码 / 警告 |
| --- | --- | --- |
| `target` 计算得 NaN/Infinity | 拒绝本次推进 | `INVALID_REQUEST` |
| 上游字段越界 | 先钳制到 `[0,1]` 再代入 | 成功 + `INPUT_CLAMPED` |
| 单次变化 >0.05 | 裁剪到 0.05 | 成功 + `CLAMPED_DELTA` |
| 结果贴边 0 或 1 | 保留边界值 | 成功 + `saturated_high` / `saturated_low` |
| `previous` 缺六维 | 用 0.5 初始化 | `DEGRADED` + `MISSING_REGULATION_DATA` |
| 周期阶段非法 | 映射为 0.50 | `MISSING_CYCLE_DATA` |
| `dt = 0` | 只重算 target，`next = prev` | 成功，贡献全 0 |
| `dt` 为负 | 按 0 处理 | 成功 + `CLOCK_REGRESSION` |
| 配置权重被改动 | 启动时拒绝 | `INVALID_REQUEST` |
| 尝试写 `mood.*` | 结构测试直接失败 | 视为契约错误 |

## 10. 禁止事项
1. 禁止写 `mood.*`、`cycle.*`、`sleep.*`、`stress.*`；只写 `regulation.*`。
2. 禁止出现真实神经递质名称、浓度或"某特征对应某物质"的表述。
3. 禁止改动 §5.1 的映射与 §5.3 的权重、§5.4 的 2700 秒与 0.05 上限。
4. 禁止在同一 tick 内引用本模块正在计算的 `fatigue_load`，必须用上一 tick 值。
5. 禁止读取同一 tick 的 09 输出（`energy`/`stability`/`closeness_need` 只取上一 tick）。
6. 禁止用周期影响向量再次写 `mood`，周期影响统一由 09 计入 `cycle` 贡献。
7. 禁止用默认值掩盖损坏数据却不给警告；禁止新增状态字段。
