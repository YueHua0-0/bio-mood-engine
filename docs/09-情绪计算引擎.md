## 1. 背景与目标
情绪引擎是唯一写入 `mood.*` 的模块。它把周期、睡眠、压力、调节特征合成七个连续维度，用惯性限制单步变化，用 home 回归防止长期漂移，用噪声提供自然抖动，并用贡献分解解释"为什么变成现在这样"。所有情绪值与 home/τ/权重均为**虚构角色状态模拟**，不是人体医学模型，不用于诊断、治疗或现实健康预测；维度名称只描述可观察的行为倾向，不对应真实心理测量。

### 1.1 关键约束（摘自 00，不得改动）
- 七个维度均为 `[0,1]`，`round6`，禁止 `NaN` / `Infinity` / `-0`。
- 单步变化：普通 ≤0.06；高严重度（`intensity ≥ 0.7`）≤0.12——超出即裁剪并追加 `CLAMPED_DELTA`；硬上限 0.15 为**断言**（`MODULE_FAILED`，不裁剪）。
- `contributions['mood.<dim>'].event` **恒为 0**，必须在代码中断言（I7）；事件只经 `stress` 单一通道进入。
- 噪声幅度 ≤0.008，不得覆盖真实输入；本模块是 `mood.*` 唯一写入者，05 的诊断性 `cycle` 贡献不得再被叠加。

## 2. 范围与非目标
**范围**：七维 home/τ；来源贡献（cycle/sleep/stress/regulation/recovery/noise/event）；alpha 混合；变化上限；贡献分解；`reason_codes`；长期稳定性约束。

**非目标**：不计算周期阶段（05）、睡眠（06）、压力（07）、调节（08）；不决定行为与交付（10/11）；不做情绪分类标签；不做 UI 展示值；不新增状态字段。

## 5. 算法与规则

### 5.1 惯性系数

```text
dt_hours = dt_seconds / 3600              // 02 已分块，单步 ≤1h
alpha    = 1 - 2 ** (-dt_hours / tau)     // tau 见 §4.3
```

`dt = tau` 时走完差距 50%；`dt = 7 * tau` 时接近稳态。`alpha` 逐维不同，不得共用同一系数。

### 5.2 来源贡献（先算 target，再按 alpha 混合）

#### 5.2.1 cycle（v2，2026-11 周期扩展）

**保留的旧通道**（四个旧四维系数必须保持 `0.6`）：

```text
cycle.energy          = 0.6 * vec.energy
cycle.sensitivity     = 0.6 * vec.sensitivity
cycle.social_drive    = 0.6 * vec.social_drive
cycle.physical_comfort = 0.6 * vec.physical_comfort
```

**保留的旧 `cycle_sensitivity` 通道**：`-0.3 * (cycle_sensitivity - 0.5)` → `stability`（08 既有调节标量，与 05 的 `anxiety_delta` 是独立输入）。

**新五维消费公式**（九个系数集中定义在 `lib/core/constants.mjs`）：

| 系数 | 映射 | 允许范围 | 初始值 |
| --- | --- | --- | --- |
| `w_pain_pc` | `pain_load` → `physical_comfort` 负向 | `[0, 0.30]` | `0.20` |
| `w_pain_energy` | `pain_load` → `energy` 负向 | `[0, 0.20]` | `0.10` |
| `w_anx_stab` | `anxiety_delta` → `stability` 负向 | `[0, 0.25]` | `0.15` |
| `w_anx_sens` | `anxiety_delta` → `sensitivity` 正向 | `[0, 0.20]` | `0.10` |
| `w_irr_stab` | `irritability_delta` → `stability` 负向 | `[0, 0.20]` | `0.12` |
| `w_irr_sens` | `irritability_delta` → `sensitivity` 正向 | `[0, 0.20]` | `0.12` |
| `w_pos_stab` | `positive_affect_delta` → `stability` 正向 | `[0, 0.20]` | `0.10` |
| `w_pos_social` | `positive_affect_delta` → `social_drive` 正向 | `[0, 0.20]` | `0.10` |
| `w_intimacy` | `intimacy_need_delta` → `closeness_need` 正向 | `[0, 0.35]` | `0.25` |

**完整 cycle contribution 公式**：

```text
cycle_contrib.physical_comfort =
    + 0.6 * vec.physical_comfort
    - w_pain_pc * vec.pain_load

cycle_contrib.energy =
    + 0.6 * vec.energy
    - w_pain_energy * vec.pain_load

cycle_contrib.stability =
    - 0.3 * (cycle_sensitivity - 0.5)
    - w_anx_stab * vec.anxiety_delta
    - w_irr_stab * vec.irritability_delta
    + w_pos_stab * vec.positive_affect_delta

cycle_contrib.sensitivity =
    + 0.6 * vec.sensitivity
    + w_anx_sens * vec.anxiety_delta
    + w_irr_sens * vec.irritability_delta

cycle_contrib.social_drive =
    + 0.6 * vec.social_drive
    + w_pos_social * vec.positive_affect_delta

cycle_contrib.closeness_need =
    + w_intimacy * vec.intimacy_need_delta

cycle_contrib.stress = 0
```

#### 5.2.2 sleep

```text
sleep.energy=-0.35*sleep_debt+0.15*(1-sleep_quality)
sleep.physical_comfort=-0.20*sleep_debt
sleep.stability=-0.15*sleep_debt

```

#### 5.2.3 stress

`mood.stress` 的目标就是 `stress.level`：

```text
stress.stress=stress.level-prev.stress
stress.energy=-0.15*stress.level
stress.stability=-0.25*stress.level

stress.social_drive=-0.10*stress.level

stress.physical_comfort=-0.10*stress.level
```

**注意**：`stress.stress` 是唯一以"目标减当前"形式表达的 `raw_term`。不要把 stress 维代入统一公式反推目标。

#### 5.2.4 regulation

```text
regulation.energy=+0.10*(arousal-0.5)
regulation.sensitivity=+0.10*(threat_sensitivity-0.5)
regulation.social_drive=+0.10*(social_reassurance_drive-0.5)
regulation.physical_comfort=-0.10*(fatigue_load-0.5)

regulation.closeness_need=+0.08*(social_reassurance_drive-0.5)
regulation.stress=0
```

#### 5.2.5 recovery / noise / event

```text
recovery.d=(home[d]-prev[d])*alpha[d]*0.6
noise.d=(u1+u2-1)*0.008
event.d=0                // event 断言恒 0
```

**跨来源的语义约束**：

- 所有周期直接贡献仍归属 `contributions['mood.<dimension>'].cycle`。**不得新增 contribution source**（09 §3 契约摘要）。
- 九个新系数为首轮仿真初值，后续可依据 M-C01–M-C18 结果校准，但调整必须走契约变更流程（00 §3.1）。
- `anxiety_delta` / `irritability_delta` / `positive_affect_delta` 是 05 新增周期派生量，与 08 既有 `cycle_sensitivity` 是**独立输入**，不得合并、互相替代或遗漏。
- 输入先 `clamp(0,1)` 再乘权重；除 `recovery`/`noise` 外，其余来源贡献都乘 `alpha[d]`：`contrib = raw_term * alpha[d]`。
- `event` 恒 0；高严重度只放宽变化上限，不改变来源表。事件已由 07 写入 `stress.level`，此处再计即重复。

### 5.3 合成与变化上限

```text
delta_raw[d] = Σ contributions[d]            // 七来源（不含 clamp），已含 alpha
limit        = severity_high ? 0.12 : 0.06    // severity_high: intensity >= 0.7
delta        = clamp(delta_raw, -limit, limit)   // 第一道：普通/高严重度上限
assert |delta| <= 0.15                           // 第二道：绝对硬边界，仅作断言，不做二次裁剪
next[d]      = clamp(prev[d] + delta, 0, 1)      // 第三道：状态区间
contributions['mood.<d>'].clamp = delta - delta_raw[d]
```

- 只存在两道**裁剪**（`0.06`/`0.12`）与一道**断言**（`0.15`）：`0.12 < 0.15`，因此"硬上限优先"不会触发二次裁剪。
- **断言检查的是 `delta`（裁剪后），不是 `delta_raw`**：由于 `limit ≤ 0.12`，正常计算下 `|delta| ≤ 0.12 < 0.15`，断言恒成立。因此该断言无法发现"权重被改大"（会被裁剪吸收，表现为 `CLAMPED_DELTA`），只能发现 **`limit` 被改大（>0.15）或 `clamp` 被绕过**——这正是它的用途，触发即 `MODULE_FAILED`。
- 若想发现"某来源绕过 alpha 或权重被改大"，应断言 `|delta_raw|` 不超过各来源的理论上界（见 §5.2 各来源系数），而不是依赖 0.15。
- 裁剪只保护单步跳变，不改变长期目标。
- 裁剪追加 `CLAMPED_DELTA`；边界饱和追加 `saturated_low` / `saturated_high`。
- 最终七维与 `contributions` 全部 `round6`，`-0` 归一为 `0`。

### 5.4 噪声

```text
for d of [energy, stability, sensitivity, social_drive, stress, physical_comfort, closeness_need]:
    u1 = rng.nextFloat(); u2 = rng.nextFloat()
    noise[d] = (u1 + u2 - 1) * 0.008
```

固定顺序、每维 2 个 float、每 tick 共 14 个；`noise` 不乘 `alpha`，幅度 ≤0.008。`rng` 必须是 `mood` 流，不得借用其他流；同一 `now` 重复执行消耗次数相同。

### 5.5 解释码

`reason_codes` 最多 16 个，按固定优先级排序：

| 条件 | 码 |
| --- | --- |
| `sleep_debt ≥ 0.50` | `sleep_debt_high` |
| `stress.level ≥ 0.55` | `stress_high` |
| 阶段为 `luteal_like` / `menstrual_like` | `luteal_like` / `menstrual_like` |
| `|recovery|` 为最大来源 | `recovery_dominant` |
| 有来源被裁剪 | `clamped_delta` |
| 任一维 ≥0.95 / ≤0.05 | `saturated_high` / `saturated_low` |
| `energy<0.35`、`stability<0.40`、`sensitivity>0.65`、`social_drive<0.30`、`closeness_need>0.65`、`physical_comfort<0.35` | 对应 `energy_low` 等 |
| 上游缺失 / 无显著来源 | `missing_upstream` / `noise_only` |

### 5.6 降级
周期缺失：阶段向量全 0 + `MISSING_CYCLE_DATA`；睡眠缺失：`0.15/0.70/0.25` + `MISSING_SLEEP_DATA`；压力缺失：`level=0.15` + `MISSING_STRESS_DATA`；调节缺失：六维 0.5 + `MISSING_REGULATION_DATA`；缺 `previous` 任一分量：用对应 home 值 + `MISSING_MOOD_DATA`，不得用 0 代替。降级只影响输入取值，不跳过惯性、裁剪或噪声。

**周期缺失的输入形式**：05 降级时**省略 `ModuleResult.derived`**（00 §4.2 / 05 §5.3），协调器不会传 `inputs.cycle.phase_vector`；本模块按全 0 向量计算并追加 `MISSING_CYCLE_DATA`。05 也会追加同一警告码，`diagnostics.warnings` 合并时按去重保留一次（02 §5.5），因此不会重复出现。

### 5.7 长期稳定性验收标准
- 30 天逐小时仿真：七维全部 `[0,1]`，均值落在 `[0.2,0.8]`。
- 7 日滚动窗口标准差 `<0.12`，无持续单边漂移；任一维贴边（0 或 1）的 tick 占比 `<5%`。
- 无输入扰动时，连续 3 天后各维与 home 的距离小于初始距离的 50%；同输入同种子逐 tick 输出完全一致，无周期锁定。

## 6. 边界与错误
| 场景 | 处理 | 错误码 / 警告 |
| --- | --- | --- |
| 任一贡献或状态为 NaN/Infinity | 拒绝本次推进 | `INVALID_REQUEST` |
| 上游字段越界 | 先钳制 `[0,1]` | 成功 + `INPUT_CLAMPED` |
| 单步变化 >0.06（普通） | 裁剪 | 成功 + `CLAMPED_DELTA` |
| 单步变化 >0.12（高严重度） | 裁剪到 0.12 | 成功 + `CLAMPED_DELTA` |
| `|delta| > 0.15` | 视为实现错误 | `MODULE_FAILED` |
| `event` 贡献非 0 | 断言失败 | `MODULE_FAILED` |
| 05 的 cycle 贡献被重复累加 | 结构测试失败 | 视为契约错误 |
| `dt = 0` / `dt < 0` | `alpha=0`，仅噪声生效 / 按 0 处理 | 成功 / `CLOCK_REGRESSION` |
| `previous` 缺维度 | 用 home 值 | `DEGRADED` + `MISSING_MOOD_DATA` |
| 输出 `-0` | 归一为 `0` | 成功 |

### 6.4 周期向量严格校验（v2 新增，优先于通用降级与限幅）

09 对 `inputs.cycle.phase_vector` 执行独立严格校验，优先于 `INPUT_CLAMPED`、`INVALID_REQUEST` 或上游限幅规则（线上 AI §6.4）。只有两种合法形状：① 恰好四字段（旧版）；② 恰好九字段（新版）。

| 输入 | 行为 | `details.path` |
| --- | --- | --- |
| `phase_vector` 属性**不存在** | 周期缺失降级（全零向量 + `MISSING_CYCLE_DATA`） | — |
| 属性存在但值为 `undefined` | 周期缺失降级 | — |
| 值为 `null` | **`MODULE_FAILED`** | `inputs.cycle.phase_vector` |
| 值为 `{}`（空对象） | **`MODULE_FAILED`** | `inputs.cycle.phase_vector` |
| 值为数组或其他非对象 | **`MODULE_FAILED`** | `inputs.cycle.phase_vector` |
| 恰好三或五至八字段（部分对象） | **`MODULE_FAILED`** | `inputs.cycle.phase_vector` |
| 恰好四字段但含未知键 | **`MODULE_FAILED`** | `inputs.cycle.phase_vector` |
| 恰好九字段但含未知键 | **`MODULE_FAILED`** | `inputs.cycle.phase_vector` |
| 字段值类型错误（`"0.2"`、`null`） | **`MODULE_FAILED`** | 对应字段 |
| 字段值为 `NaN` / `Infinity` | **`MODULE_FAILED`** | 对应字段 |
| 字段值越界 | **`MODULE_FAILED`** | 对应字段 |

所有 `MODULE_FAILED` 情况的内部异常必须保留 `module='mood'`、精确 `path` 和原始 `got` 值。coordinator 对带 `code` 的异常原样透传。

旧四维兼容（恰好四字段时）：缺失五个新维度按 0 处理，**不因旧四维输入额外扣减 `pain_load`**；旧四维字段**不乘 profile**。
